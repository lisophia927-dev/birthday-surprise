NEON_BDAY_v3_WITH_HAPPY_BIRTHDAY_SONG
=====================================

RUN LOCALLY
1. Open a terminal in the folder containing index.html.
2. Run: python3 -m http.server 8000
3. Open: http://127.0.0.1:8000

PUBLISH ON GITHUB PAGES
Repository: https://github.com/lisophia927-dev/birthday-surprise
1. Settings > Pages.
2. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
3. Wait for a successful Pages deployment in Actions.
4. Published URL: https://lisophia927-dev.github.io/birthday-surprise/

MUSIC
The Happy Birthday melody is synthesized in the browser after a button click. No MP3 is required or bundled. Browsers may require user interaction before playing sound.

MEDIA
Selected files are listed locally and are not uploaded or embedded in the share link. Host media over public HTTPS and paste those public URLs into the media field. Do not share private or sensitive files.

SAFETY
Matrix rain is decorative only. The site does not execute terminal commands, scan devices, collect visitor data, or request passwords, OTPs, payment details, camera, or microphone access.
